# 日本語拡張ストア（個人用）

Keiyoushiの拡張機能を日本語化・改修した個人用フォークです。Keiyoushiの公式配布ではありません。

対象はDMM/FANZA、少年ジャンプ＋、となりのヤングジャンプ、カドコミ、ブックウォーカーの5拡張です。

利用方法・変更内容・ビルド方法・実機確認の状況は[日本語ガイド](README-JA.md)を参照してください。

ストアの公開は準備中です。現在、GitHub上で利用できるストアURLはまだありません。
